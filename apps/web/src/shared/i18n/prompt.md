# Перевод интерфейса Who Ruined CS2

Переводи UI аналитического сервиса Counter-Strike 2 естественно, кратко и без
обвинительной риторики. Источник — английские строки текущего namespace из
`translation-tasks.json`. Работай с одним namespace за раз.

1. Открой секцию файла задач и соответствующие целевые JSON в `locales`.
   Не сканируй остальной проект для отдельной задачи перевода.
2. Переводи значения указанных ключей. Не меняй ключи, namespace, структуру
   JSON и уже проверенные строки вне задачи.
3. Сохраняй плейсхолдеры `{{name}}`, `{{count}}`, теги-обёртки,
   ссылки и переносы строк. Не добавляй HTML или форматирование.
4. Суффиксы `_one/_few/_many/_other` и другие создаёт sync по CLDR.
   Переводи только формы, существующие в целевом файле. Для дополнительных
   форм исходником служит EN `_other`. Не удаляй `{{count}}`.
5. Не переводить бренд, ники, Steam, FACEIT, CS2, идентификаторы карт.
   K/D/A, ADR, KAST, T и CT — игровые сокращения.
   Trade / размен — ответное убийство противника, только что убившего
   союзника, а не обмен людьми или предметами. Utility — гранаты и их
   применение; flash — световая граната. Если местный игровой термин
   неоднозначен, используй краткое описание действия.
6. «Недоступно» не значит «ноль». «Низкая уверенность» не значит «виновен».
   Обычная смерть — факт события, а не доказанная ошибка.
7. Для RTL-языков проверь интерфейс с `dir=rtl`. Числа, счёт, SteamID и
   игровые сокращения должны оставаться понятными.
8. Файлы: UTF-8, JSON, два пробела, новая строка в конце.

Отчёт группирует задачи по namespace: `languages` — языки, `keys` — ключи
и английский текст. Это объединение задач: не перезаписывай уже проверенную
строку языка только потому, что она нужна другому языку. При сомнениях запусти
sync с `--langs=<language> --files=<namespace> --dry-run` и смотри stdout.

После перевода выполнить `npm.cmd run i18n:sync`, затем `npm.cmd run i18n:check`.
Отчёт и снимок не редактировать вручную. Если изменённый EN не требует
изменения перевода, проверить весь выбранный namespace и использовать
адресный `--acknowledge`, как описано в корневом AGENTS.md.
