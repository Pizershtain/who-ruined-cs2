# Проверка длинных переводов

Открой `compaction-tasks.json`, созданный командой `npm.cmd run i18n:compact`.
Это кандидаты для проверки, а не список доказанных ошибок вёрстки.

Проверяй один namespace и язык за раз. Сокращай фразы только если это нужно
интерфейсу; сохраняй смысл, оговорки о достоверности, плейсхолдеры и CLDR-формы.
Не подменяй отсутствие данных нулём или утверждением об ошибке игрока.
Не редактируй ключи, английский источник, snapshot и отчёты вручную.

После изменения: `npm.cmd run i18n:check`, затем проверить соответствующую
страницу на desktop и 320/390 px. Если более длинная фраза помещается и яснее
короткой, оставь её.
