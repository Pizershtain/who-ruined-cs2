# Композиция внутренних экранов: спецификация

Рабочий промт для вёрстки отчёта, страницы игрока и справки. Источник — публичная
страница coinbase.com/ru, измеренная в браузере при ширине окна 1280 px. Значения
Coinbase приведены как есть, рядом — то, во что они переводятся в нашей тёмной теме.

## Что измерено у Coinbase (1280 px)

| Элемент | Значение |
| --- | --- |
| Контейнер секции | `max-width: 1200px; padding: 80px 32px`, содержимое по центру |
| Секция-фича | высота 596 px, фон белый или светло-серый `rgb(238 240 243)` на всю ширину, соседние секции чередуют фон |
| Раскладка | `display: flex; gap: 48px`, две колонки по 542–544 px |
| Сцена (картинка) | 542 × 434 px, `border-radius: 56px`, `overflow: hidden`, заливка серым или изображение на всю площадь |
| Чередование | сцена слева → справа → слева; текст занимает вторую колонку |
| Главная секция | высота 740 px, сцена 584 × 584 px, `border-radius: 56px` |
| Ярлык над заголовком | пилюля с обводкой, капс ~12 px, иконка слева, `border-radius: 999px` |
| Заголовок секции | 44 px / 48 px, **начертание 400**, цвет почти чёрный `rgb(10 11 13)` |
| Заголовок главной | 80 px / 80 px, начертание 400 |
| Абзац | 16 px / 24 px (18 / 28 в главной), серый, одна-две фразы |
| Кнопка | одна, чёрная пилюля 48 px, белый текст 16 px, сразу под абзацем |
| Текстовая колонка | ярлык → заголовок → абзац → кнопка, выравнивание по левому краю, ничего больше |
| Шрифт | CoinbaseDisplay для заголовков, CoinbaseSans для текста |

Главное свойство: в одной секции ровно одна мысль, один визуал и одно действие.
Между центрами соседних секций около 600 px, поэтому в кадре всегда одна секция.

## Перевод в нашу тему

| Параметр | У нас |
| --- | --- |
| Фон страницы | `--bg` с мягким ASCII-полем и свечениями; чередование секций — тёмная полоса `.band` на всю ширину |
| Сцена `.stage` | стекло: `rgb(var(--glass) / .06)` поверх фона, `backdrop-filter`, обводка `--line`, `border-radius: 40px` (56 на тёмном выглядит игрушечно), `padding: 32px`, `min-height: 434px`, содержимое по центру по вертикали |
| Сетка `.story` | две равные колонки, `gap: 48px`, `padding-block: 80px`, контейнер 1180 px; на экранах уже 900 px — одна колонка, сначала текст, потом сцена |
| Ярлык `.story-label` | пилюля с обводкой, 12 px, капс, разрядка .08em, цвет `--accent` |
| Заголовок `.story h2` | `clamp(2rem, 3.4vw, 2.75rem)` / 1.1, начертание 400, `letter-spacing: -.015em` |
| Заголовок главной `.story.hero h1` | `clamp(3rem, 6vw, 5rem)` / 1, начертание 400 |
| Абзац `.story-lead` | 1rem / 1.5, цвет `--text-2`, не длиннее 46 символов в строке |
| Кнопка | одна пилюля 48 px: `--accent` с тёмным текстом для главного действия, стекло для второстепенного |
| Чередование | нечётные секции — сцена слева, чётные — справа (класс `alt`) |

## Что лежит в сцене на каждом экране

Отчёт о матче: счёт (главная) → итоги (MVP и Who Ruined) → табло → лента раундов →
графики (вкладки внутри сцены) → ключевые моменты (первые 4 и «ещё»).
Игрок: имя и пять цифр (главная) → экспериментальная оценка → ключевые действия →
сильные стороны и гранаты → графики → журнал событий (первые 12 и «ещё»).

## Правила

1. Одна секция — один визуал. Никаких вторых панелей, карточек внутри сцены и подзаголовков в текстовой колонке.
2. Сцена не прокручивается по вертикали. Если данных больше, чем влезает, показываем порцию и кнопку «ещё»; сцена растёт вместе со страницей. Горизонтальная прокрутка допустима только для ленты раундов и широкой таблицы. Полная версия раздела открывается окном `Sheet`; внутри окна прокрутка допустима.
3. Текстовая колонка: ярлык, заголовок, один абзац, не больше одной кнопки. Подписи-дисклеймеры уходят в абзац, а не под визуал.
4. Элементы управления визуалом (переключатель команд, фильтр моментов, выбор метрики) живут внутри сцены, в её верхней части, как элементы интерфейса на «картинке».
5. Все тексты через `t()`, контраст по `pnpm design:contrast`, анимации 120–240 мс и уважают `prefers-reduced-motion`.
6. Значок «развернуть» — голый глиф без обводки в верхнем внешнем углу текстовой колонки, на уровне верхнего края сцены.
7. Первая секция (`hero`) занимает весь первый экран: навигация по разделам появляется только после прокрутки.
8. Числа набираются моноширинным шрифтом (`--font-num`), текст — системным (`--font-ui`, `--font-display`).

## Отступления от Coinbase

- Скругление сцены 40 px вместо 56: на тёмном фоне 56 выглядит игрушечно.
- Чередующийся фон секций — тёмная полоса с мягкими краями, а не светло-серая с резкой границей.
- Сцена — стекло с тинтом 6 % поверх ASCII-фона, а не заливка картинкой.
