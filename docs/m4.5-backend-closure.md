# M4.5 backend closure

Status: **PASS / LOCAL ONLY / OWNER GIT REVIEW PENDING**.

## Owner decision and dependency boundary

The obsolete `GET /api/v1/matches/:id/experimental-rating` endpoint is fully
unregistered. Neither its default P2 form nor `?model=c2-s2` can be enabled by
the former `ENABLE_EXPERIMENTAL_RATING` flag. Its public DTOs, OpenAPI exposure,
projector, route tests and rating-only preparation CLI were removed.

The internal C2+S2 mathematical kernel, prepared sidecar schema and worker
prepared-profile builder were retained. They are not competing public ratings:
the frozen H2/H1 participation policies use them to construct and reconstruct
their six family inputs. Removing them would break the active owner workflow.

No frontend source, H2/H1 coefficients or digests, active response DTO,
`match-result@1` format, parser/normalizer, Prisma schema or database migration
was changed.

## Docker smoke

A clean online Compose build produced API and worker images. An isolated
loopback-only project accepted one previously permitted real demo and completed
the parse job. It stored one canonical gzip result and retained zero upload,
report or worker-temporary files. The active rating, ordinary match and report
reads returned 200; retired routes returned 404; the forbidden policy selector
returned 422. A RESCORE job completed. After restarting both API and worker,
the active rating remained readable. Container resource constraints and health
checks remained active. The isolated data directory, including SQLite and all
private identifiers, was then deleted.
