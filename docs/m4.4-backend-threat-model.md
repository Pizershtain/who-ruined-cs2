# M4.4 backend threat model

Status: implementation baseline recorded before M4.4 code changes. The product
is local-first. HTTP clients on the local machine and browser content capable
of reaching loopback are in scope. Malware or another process that can modify
SQLite or files under `DATA_DIR` is outside the HTTP security boundary.

## Effective attack surface before hardening

The API has the global `/api/v1` prefix and these controller routes:

| Method | Route | Input and storage boundary | Existing guard before M4.4 |
| --- | --- | --- | --- |
| GET | `/health` | none | fixed response |
| POST | `/matches` | multipart `demo` | random disk filename, `.dem` suffix, 512 MiB stream limit, free-disk admission, Source 2 header |
| GET | `/jobs/:id` | job id | database lookup only |
| GET | `/matches` | optional cursor | 20-row database page |
| GET | `/matches/:id` | match id | canonical result or legacy artifact reader |
| GET | `/matches/:id/rounds` | match id | same reader |
| GET | `/matches/:id/analytics` | match id | same reader plus M2 schema |
| GET | `/matches/:id/players/:playerId/analytics` | match/player ids | participant lookup |
| GET | `/matches/:id/experimental-participation-rating` | query string | default-off flag; every present `policy` rejected; canonical active result |
| DELETE | `/matches/:id` | match id | active-job refusal and owned-path deletion |
| GET | `/matches/:id/report` | version/config hash | canonical/legacy report reader |
| GET | `/matches/:id/players/:playerId/report` | match/player ids | report projection |
| POST | `/matches/:id/rescore` | JSON body | Zod request schema and known scoring config |

Swagger is exposed at `/api/docs`. No file-serving, diagnostics or HTTP admin
route exists. `rating:rebuild` and `result:migrate` are local worker CLIs only.
The API defaults to `127.0.0.1`; Compose deliberately binds `0.0.0.0` inside
the container but publishes `127.0.0.1:${API_PORT}:3000`. The worker publishes
no port. Before M4.4 the API did not enable CORS, so same-origin/proxy requests
worked and cross-origin browser callers received no CORS permission.

## Threat and mitigation matrix

| Boundary | Attacker input/capability | Baseline protection | Verified gap and severity | M4.4 mitigation / regression | Remaining risk |
| --- | --- | --- | --- | --- | --- |
| host/container exposure | connect to configured API socket | loopback host publication; worker private | unsafe override remains possible by operator, low/local | validate bind/ports and document override | operator can intentionally expose the service |
| browser origin | arbitrary `Origin` and state-changing request | no CORS headers | no explicit allowlist or origin policy, medium/local-browser | explicit configurable local allowlist and actual-origin tests | CORS is not authentication; non-browser local clients remain capable |
| route params | traversal, NUL, encoded separators, overlong IDs | DELETE had one regex; path resolver constrained stored paths | most endpoints queried DB before validating IDs; malformed cursor could become 500, medium | shared opaque-ID/query validation before DB/filesystem work | Unicode display names remain legitimate report data, not route IDs |
| query/body | arrays, duplicates, unknown keys, malformed/large JSON | scoring body uses Zod; Express default JSON limit | unknown query keys were ignored and duplicate selectors depended on coercion, medium | route-specific exact query-key validation and typed body errors | Node rejects some oversized headers before Nest can add its JSON envelope |
| multipart upload | chunked, false length, abort, large file | disk streaming, size counter, disk reserve, cleanup | no explicit concurrent admission or request deadline, high for local resource pressure | finite upload slots, queued-job cap, server timeouts, typed 429/503 | intentionally slow client can occupy one configured slot until deadline |
| SQLite queue | many distinct accepted demos | unique SHA and worker lease | no finite queued-job admission bound, medium/high | DB-based pending-job cap before retained upload commit | multiple API processes need the same DB cap, not only an in-memory semaphore |
| canonical gzip | small compressed/high expansion, corrupt/truncated data | SHA, Zod schema, owned path, symlink checks | `readFile` + `gunzip` had no compressed or output ceiling, high | independent compressed/uncompressed bounds and streaming inflate abort | valid future formats larger than configured ceiling require explicit config change |
| legacy gzip | corrupt or oversized normalized/report/sidecar | schema validation in most readers | several readers used unbounded `gunzip`, medium | reuse bounded private gzip reader where touched by HTTP | owner-only worker migration readers remain trusted local operations |
| canonical path | DB-controlled relative path, symlink/junction | canonical root confinement and component `lstat` | tested design is safe against ordinary traversal/symlink, low | retain and add negative regressions | filesystem administrator can race/replace objects and is out of scope |
| read/delete/rebuild | concurrent immutable read and replacement/deletion | immutable versioned file, DB pointer, owned deletion | expected ENOENT had to remain typed; no partial bytes expected, medium | repeat concurrency/fault tests after bounded reader | SQLite/filesystem are not one native transaction |
| parser process | malformed/hung native parser | owned child, hard deadline, SIGKILL, leases/fencing | no new confirmed M4.4 defect | retain M4.2 fault tests and Docker limits | OS/container OOM can terminate worker; lease recovery is eventual |
| public error/logging | crafted parser/DB/path errors | safe filter and type-only internal log | framework errors all mapped to `INVALID_DEMO`; request correlation not accepted from caller, low/medium | stable typed mapping, generated request id, privacy tests | legitimate match reports contain player identity by product design |
| active rating | HTTP selection of H1/H2 | server env + owner CLI; `policy` rejected | encoded/duplicate/array cases needed HTTP proof, high policy invariant | strict raw query-key detection and negative matrix | operator controls env/CLI locally |
| retired experimental API | old P2/C2+S2 URL | M4.5 unregisters it after explicit owner decision | stale flag or OpenAPI registration could revive it | route/DTO/flag removal plus 404/OpenAPI regression | historical private artifacts remain inert on disk |

No demonstrated issue justifies authentication, Redis, PostgreSQL, public
deployment, a blacklist, a scoring change or a database migration in M4.4.
