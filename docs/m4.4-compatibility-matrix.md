# M4.4 backend compatibility matrix

This matrix records the behavior observed before implementation and the intended
M4.4 result. It is the Gate A change boundary, not evidence that later tests
have already passed.

| Surface | Before M4.4 | Intended after M4.4 | Compatibility rule |
| --- | --- | --- | --- |
| API host | host default `127.0.0.1`; Compose host port loopback only | unchanged and tested from effective config | no broader bind |
| CORS | disabled | explicit local configurable allowlist; no hostile-origin permission | same-origin and known Vite origins continue working |
| Swagger/health | public on the local API | unchanged route and bounded metadata | no seed/env/path disclosure |
| upload size | 512 MiB exact stream limit; +1 rejected | unchanged, plus concurrency and time bounds | exact boundary remains admitted; semantic demo validation is separate |
| upload pressure | no explicit simultaneous-upload or queued-job ceiling | typed `429 UPLOAD_BUSY` and `503 QUEUE_SATURATED` | accepted in-flight jobs remain valid |
| JSON/header/query | Express/Node defaults; partial per-route validation | explicit size/time config and strict keys/types/opaque IDs | valid documented calls unchanged |
| canonical gzip | checksum/schema/path checks but unbounded inflate | independent compressed and decompressed ceilings | `match-result@1` schema and bytes unchanged |
| canonical read errors | typed `409 REPORT_CORRUPT`/`REPORT_POLICY_MISMATCH` | same codes for corruption/policy; no partial JSON | documented 409 semantics unchanged |
| participation rating | feature flag; server-selected H2/H1; any detected policy rejected | all empty/duplicate/array/encoded `policy` forms rejected 422 | response remains `m4.3-participation-rating@1` and policy-neutral |
| owner policy switch | env plus `rating:rebuild` CLI | unchanged | no HTTP owner/admin operation |
| legacy P2/C2+S2 | default-off compatibility route retained during M4.4 | retired by explicit owner decision in M4.5 | shared H2/H1 preparation kernel remains internal |
| DELETE | refuses active jobs; owned path cleanup | unchanged contract, retested under races | 409 active, 204 completed, no foreign deletion |
| rescore/reports | existing production contracts and canonical fallback | unchanged; strict request/query validation only | no scoring/DTO/schema change |
| worker parser | one worker loop, one owned native child, timeout and lease fencing | unchanged; fault regressions rerun | no parser/normalizer change |
| storage/database | one `match-result@1` plus SQLite accounting | unchanged | no Prisma migration |

## Owner decision resolved in M4.5

The owner chose full HTTP retirement rather than a new scrubbed compatibility
DTO. The old route, flag and response schemas were removed. Historical files
were not deleted, and the internal prepared inputs required by H2/H1 remain.
