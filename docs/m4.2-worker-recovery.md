# M4.2 worker recovery contract

## States and ownership

Active states are `PARSING`, `NORMALIZING`, `VALIDATING`, `FEATURIZING` and
`SCORING`. Terminal states remain `COMPLETED`, `PARTIAL` and `FAILED`. A claim
is valid only for the tuple `(jobId, leaseToken, unexpired lease)`. Heartbeat
must be shorter than one third of the lease; invalid configuration fails at
startup.

On abrupt death the durable stage remains visible until expiry. The next worker
atomically clears the expired token, requeues the same job, increments its
attempt on claim and recomputes from the original demo or reuses a fully
validated immutable M2 artifact. No checkpoint is treated as complete merely
because its stage name was persisted.

On SIGTERM/SIGINT the worker aborts its owned parser supervisor, waits for child
cleanup and conditionally returns the job to `QUEUED`. After the configured
attempt budget, recovery ends as `FAILED/WORKER_RECOVERY_EXHAUSTED`.

## Publication ordering

1. Native child writes only a unique provisional snapshot.
2. Parent validates it and always removes it after reading.
3. Normalization and M2 validation run before sidecars/features.
4. Prepared sidecars and M2 cache publish immutably.
5. Scoring reports publish immutably and their unique DB row is upserted.
6. A fenced SQLite transaction updates Match and the terminal Job together.

Cross-resource atomicity is not claimed. A crash after a final file but before
the DB transition is handled by binding/schema validation and reuse. A crash
before final publication leaves only a provisional file, which startup
reconciliation removes. A final-path mismatch is never overwritten.

## Retry classification

- Process/container interruption: bounded retry after lease expiry, or immediate
  requeue after graceful signal.
- `PARSE_TIMEOUT`: typed terminal failure; deterministic hangs do not loop.
- Parser failure/corrupt or unsupported input: typed terminal parser failure.
- Validation failure: `VALIDATION_FAILED`.
- Scoring/publication conflict: `SCORING_FAILED`; existing valid bytes remain.
- RESCORE: reads the stored M2 artifact and never invokes the demo parser.

## Configuration

Defaults: 120 s parse timeout, 30 s lease, 5 s heartbeat, three attempts,
5 s child-kill grace, 512 MiB compressed snapshot bound and 1.5 GiB inflated
snapshot bound. Docker Compose passes these values to the worker. Test runs use
shorter leases/timeouts only in a dedicated project and data root.
